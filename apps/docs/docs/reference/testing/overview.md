# Testing

Testing is provided by fast app-level Vitest suites and TypeScript checks.

| Area   | Tooling | Location                 |
| ------ | ------- | ------------------------ |
| Strapi | Vitest  | `apps/strapi/tests`      |
| Mapp   | Vitest  | `apps/mapp/**/*.test.ts` |
